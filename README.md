## Who this course is for

IT support specialists, desktop technicians, help-desk technicians and entry-level IT professionals working towards the CompTIA A+ certification.

**Prerequisites:** minimum 3 GCE 'O' Level passes including English, at least 1 year of working experience, basic computer operation skills, aged 18–65.

## What you'll be able to do

| | Learning outcome |
| --- | --- |
| **LO1** | Diagnose technical issues in network operations and implement procedures to resolve root causes. |
| **LO2** | Troubleshoot technical issues and perform advanced infrastructure configurations. |
| **LO3** | Develop action plans for upgrades and propose improvement ideas based on user needs. |
| **LO4** | Test infrastructure systems and organise information for developing user guides. |

Aligned to the Skills Framework TSC **Infrastructure Support (ICT-OUS-3007-1.1)**.

## How to use this repository

1. Read the [Learner Guide](LG-CompTIA-Certified-A-Training-Core-1-and-Core-2.md) introduction and the **safety section** before any hardware lab.
2. Open the [labs index](labs/README.md) and work the labs in order — later troubleshooting labs build on earlier configuration labs.
3. Each lab folder contains `README.md` (the procedure) and `worksheet.md` (your evidence record), plus a print-ready PDF of each.
4. Complete the **Test it** verification in every lab before moving on — it is what the practical assessment mirrors.
5. Sit the [practice exam](https://exams.tertiaryinfotech.com) to find the domains to revise before booking the real exams.

### Safety

Several labs involve opening computer equipment.

- Disconnect mains power and hold the power button for 15 seconds to discharge before working inside any machine.
- Wear an anti-static strap; hold boards and cards by their edges.
- **Never open a power supply unit or a CRT monitor** — both retain a lethal charge after being unplugged.
- Never puncture, compress or charge a swollen lithium battery.

## Assessment

Learners are assessed as **Competent** or **Not Yet Competent** on two instruments:

- **Written Assessment (WA)** — short-answer questions, 1 hour, open book.
- **Practical Performance (PP)** — hands-on support, configuration and troubleshooting tasks, 1 hour, open book.

A minimum **75% attendance** is required to be eligible for assessment and funding.

> Assessment papers and answer keys are confidential and are **not** published in this repository.
