The labs cover PC hardware, mobile devices, networking, virtualization and cloud, operating systems, command-line tools, security, malware response, software troubleshooting, backup and recovery, documentation, change management, safety, and professional operational procedures.

## How to Use

1. Open the learner guide first and review the lab safety checklist.
2. Complete the labs in order because later troubleshooting labs reuse hardware, OS, networking, and documentation practices from earlier labs.
3. Use a Windows PC, virtual machines, mobile device settings screens, and safe demo hardware where available.
4. Do not open power supplies or handle live electrical components.
5. Record screenshots, commands, symptoms, fixes, and documentation notes in your lab journal.
