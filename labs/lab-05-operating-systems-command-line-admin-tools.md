# Lab 05 - Operating Systems, Command Line, and Admin Tools

## Objectives

- Use Windows administrative tools.
- Review safe command-line utilities.
- Compare file systems.
- Review macOS and Linux basics.

## Steps

1. Open Task Manager and review performance metrics.
2. Open Device Manager and identify device categories.
3. Open Disk Management and review volumes without changing them.
4. Open Event Viewer and locate system and application logs.
5. Run help-only commands such as `sfc /?`, `chkdsk /?`, `gpupdate /?`, and `gpresult /?`.
6. Review NTFS, FAT32, exFAT, ext4, APFS, and HFS+.
7. Review safe file commands such as `dir`, `copy`, and `robocopy /?`.
8. Review Linux basics: `pwd`, `ls`, `cd`, `ps`, `grep`, `chmod`.
9. Review macOS concepts: Finder, Spotlight, Time Machine, and Keychain.
10. Map each tool to a support scenario.

## Validation

- Administrative tools are identified.
- Commands are used safely.
- File systems are compared correctly.
- Tool-to-task map is complete.

## Review Questions

1. When would you use Device Manager?
2. What is Event Viewer useful for?
3. What does NTFS support that FAT32 does not?
4. Why should Disk Management be used carefully?
