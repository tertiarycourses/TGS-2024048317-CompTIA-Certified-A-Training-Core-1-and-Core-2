# Hands-On Labs — CompTIA Certified A+ Training (Core 1 and Core 2)

> **Course code:** TGS-2024048317  ·  **Version v7.1** · 19 August 2026  
> **Register:** https://www.tertiarycourses.com.sg/wsq-comptia-certified-a-training-core-1-and-core-2.html

54 hands-on labs across the nine CompTIA A+ exam domains. **Each lab has its own folder** containing the full procedure (`README.md`) and a fill-in worksheet (`worksheet.md`).

Every lab runs on training hardware provided in class or in your web browser — see [tools.md](tools.md) for the toolkit. There is nothing to install and nothing to license.

## How to use these labs

1. Read the objective and the goal first, so you know what the lab is proving.
2. Work the steps in order — later steps depend on earlier ones.
3. Complete the **Test it** verification before moving on. It is what the Practical Performance assessment mirrors.
4. Fill in `worksheet.md` as you go and keep it as your evidence record.
5. Answer the review questions from memory — if you cannot, revisit the concept in the Learner Guide.
