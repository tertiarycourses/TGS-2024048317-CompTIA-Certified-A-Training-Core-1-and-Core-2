# Lab 03 - Virtualization, Cloud, and Hardware Troubleshooting

## Objectives

- Compare virtualization types.
- Explain cloud service models.
- Review VM resource settings.
- Apply hardware troubleshooting methodology.

## Steps

1. Compare Type 1 and Type 2 hypervisors.
2. Review VM resource settings: CPU, RAM, disk, network, and snapshots.
3. Compare IaaS, PaaS, and SaaS.
4. Compare public, private, hybrid, and community cloud.
5. Inspect or create a small VM if permitted.
6. Record VM configuration settings.
7. Review troubleshooting methodology.
8. Match symptoms to likely causes: no POST, no boot, overheating, BSOD, black screen, slow performance.
9. Create a troubleshooting plan for one hardware symptom.
10. Define when to escalate.

## Validation

- Virtualization and cloud terms are explained clearly.
- VM settings are documented.
- Troubleshooting plan follows the methodology.
- Escalation point is reasonable.

## Review Questions

1. What is a hypervisor?
2. What is the difference between IaaS and SaaS?
3. Why should one change be made at a time?
4. What evidence would you collect for a no-boot issue?
