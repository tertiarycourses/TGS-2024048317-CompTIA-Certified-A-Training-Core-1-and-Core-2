# Lab 08 - Operational Procedures, Documentation, Change, and Safety

## Objectives

- Write ticket notes.
- Create change and asset records.
- Apply safety procedures.
- Practise professional communication.

## Steps

1. Create a sample support ticket from a user report.
2. Record user, device, symptom, impact, priority, and contact details.
3. Write troubleshooting notes in chronological order.
4. Create a change request with purpose, scope, risk, backout plan, and approval.
5. Create an asset record with hostname, serial number, asset tag, owner, location, warranty, and OS.
6. Review ESD prevention.
7. Review power safety, lifting safety, and component handling.
8. Write a professional user update message.
9. Write a short knowledge base article for a resolved issue.
10. Complete the final A+ readiness checklist.

## Validation

- Ticket note is useful to another technician.
- Change request includes backout plan.
- Asset record has enough detail.
- Communication is professional.

## Review Questions

1. Why is documentation part of technical work?
2. What is a backout plan?
3. Why are asset tags important?
4. How does professional communication affect support quality?
